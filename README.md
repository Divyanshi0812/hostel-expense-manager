# HOSTEL EXPENSE MANAGER

##Overview
In this project, I have made a python based expense tracker that helps the user to keep track of the monthly budget he or she has . It keeps record of all expenses and shows them category-wise and warns the user whether he or she is using more than the budget set or not.

This software lets a user enter his monthly budget , add daily expenses and get the total amount of money that has been spent , money left and saved.

##Features
-Setting monthly budget or pocket money
-Adding expenses through
	-Date
	-Category
	-Amount
	-Description
-Spending tracking by categories:
	-Food
	-Travelling
	-Shopping
	-Studies
	-Others
-Viewing total expense
-Viewing remaining money and savings
-Showing expense history
-Warning user about his spending
-User-friendly command line menu

##Technologies/ Tools used

-Basic python input/output tools
-Terminal/ command line interface
