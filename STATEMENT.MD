# Problem Statement 

Hostel staying students usually have trouble controlling their monthly expenditures.
Without any effivient tracking system , it becomes tough to monitor the amount of money spent on various needs such as meals , travelling , shopping , books for studying, etc . As a result , they start spending too much money.

there is no efficient and affordable expense tracking sysytem that would help students keep track of the money spent, manage their monthly budget and become aware of how much money they have left.

# Scope of project 

the scope of this project is developing an initial hostel expense manangement syatem that would help students to:

-define their monthly budget
-input daily expenses
-group expenses by type
-Calculate the total spending
-see how much money is left and what savings there are
-see history of expenses 
-get warning about overspending

This project will develop a desktop console application written in python programming language. The scale of the project is small and will not involve data base management,logging-in options and cloud service

# Target user

The targeted users of this application are:

-college students who reside in hostel
-students who have a fixed monthly budget
-people who need an efficient and inexpensive means to monitor personal expenditures
-beginners studying python programming through a practice example

# High level feature

the features included in the system are as follows:
Budget Input :the user enters their monthly budget.
Expenditure Entry : the user enters his expenditure with the details of date, category, amount and description
Expenditures categories: the expenses entered by the user are divide into food, travel, shopping, study and miscellaneous categories
Summary of expenditure:  the system computes total expenditure, remaining balance and savings.
Expenditure history : the user is able to see the history of his recorded transaction
Budget Alarm : the app alerts the user whenever he spends over 80% of the budget or exceeds the limit of the month
Menu-based system: this system provides a menu based interface for interaction
